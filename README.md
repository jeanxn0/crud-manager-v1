# Loja de Games

Loja de jogos desenvolvida em Java com Servlets, JSP e MySQL. A vitrine reúne 42 jogos com capas, busca por título e filtros por plataforma, incluindo PC, PlayStation, Xbox e Nintendo Switch.

Visitantes podem criar uma conta e fazer login. O painel administrativo permite cadastrar, editar, listar e excluir jogos e vendas, com paginação nas listagens.
